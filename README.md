# Herramientas clínicas · guía de parciales

Study material for the course **Herramientas de la Psicología Clínica**, Facultad de Psicología, Universidad de la República (Udelar), Uruguay.

The site is a single page. It contains worked cases solved from start to finish, with every score calculated in view. The diagrams build up as you scroll.

- **Parcial 1:**
  - Bender-Koppitz.
  - Dibujo de la Figura Humana (Koppitz).
  - WISC-V theory.
  - Two cases (Mateo and Sofía).
  - Exam template and reference tables.
- **Parcial 2:**
  - Bridge from psychometric to projective techniques, with Caride's 4 levels.
  - The WISC-V calculation, with an interactive calculator.
  - Test de la Familia (Corman), Persona bajo la lluvia and HTP.
  - TAT and CAT.
  - Rorschach (full level, with psicograma, tipo vivencial and Neiger's IR).
  - Informe and devolución.
  - Integrated cases: Tomás (WISC-V + Familia), Camila (PBLL + TAT), Martín (HTP + Rorschach), and the December 2019 exam (Sergio) solved.

**Planned URL:** https://pasquinell.github.io/herramientas-clinicas/ (it changes if the repo has another name).

> This is study material. It does not replace supervised training or the official manuals. Apart from the 2019 exam, the cases are fictitious.

## Structure

- `index.html`: the whole site (HTML, CSS and JS in one file, no build step).
- `img/tat/`: the 30 TAT plates (plate 16 is blank and has no image).
- `img/rorschach/`: the 10 Rorschach plates.
- `fuentes/`: course material used as the content base. **Do not publish it.** See the note below.
- `doc/README.md`: technical documentation.
- `doc/tools/`: verification scripts.
- `.nojekyll`: makes GitHub Pages serve the files as they are.

## Sources

Each block has a fold-out list of its sources. The common base is the course bibliography and the December 2019 exam, checked against the literature and web searches.

Quote markers:
- ⚑: the wording was checked.
- ≈: faithful paraphrase, or a quote seen only in a secondary source.

The WISC-V conversion tables, critical values and base rates belong to the manual. Wherever they appear, they are illustrative and labelled as such.
