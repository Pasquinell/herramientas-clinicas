# Project documentation · Herramientas clínicas

This file records what was built, the criteria behind it, and how to keep editing and verifying it. It is meant for picking the work up again in another session without rebuilding the context.

## 1. What it is

`index.html` is a single page with no build step. It is a study guide for Herramientas de la Psicología Clínica (Udelar).

- The **Parcial 1** part already existed and is kept: method, the Mateo and Sofía cases with Bender and DFH, the template, WISC-V theory and the tables.
- The **Parcial 2** part was added in November 2026.
- The style was unified with the sibling sites `../clinica1_fund_PsA` and `../tcc_terapia`: topbar, automatic index, parcial dividers, light/dark mode, scroll progress.

## 4. Two scrolly engines (do not mix them)

- **P1 (JS):** `.scrolly > .stage + .steps > .step > .card`. Steps are objects `{zoom, focus, show, tally…}` and the SVG viewBox is animated. All of it is generated by `renderCase()`.
- **P2 (static, from tcc):** the `.dsc` namespace was chosen so it does not collide with P1.

  ```html
  <div class="dsc [flip]" id="dsc-…">
    <div class="dsteps"><div class="dstep"><div class="sc">…</div></div>…</div>
    <div class="dfig"><div class="frame"><svg viewBox="0 0 600 H" role="img" aria-label="…">
      <g data-s="N">…</g>   <!-- visible when step ≥ N -->
      <g data-show="2,3">…</g>   <!-- visible only on those steps -->
    </svg><div class="cap">…</div></div></div>
  </div>
  ```

  - The active step is the last one whose top edge is above 58 % of the viewport height (78 % on mobile).
  - `data-off="N"` with `.fade` dims an element from step N on.
  - `dscHook(id, n=>…)` lets a block run JS on each step.
  - `data-show` uses the `hidden` **attribute** (`toggleAttribute`), because SVG elements do not have the `hidden` property.
- P2 SVG vocabulary:
  - text: `.ti .sm .xs .hw` (Caveat) `.mo`;
  - boxes: `.bk .ba .bs .bv .bi .bl`;
  - lines: `.lnk .lnd .lk .la .ls .lv .li .lg`;
  - pencil: `.pen .penf`.
- The base text rule uses `:where(...)`, so it does not override `.sm` or `.hw`. This was a real bug: sizes and handwriting were being ignored.

**P1 class names that P2 must not reuse:** `card step steps scrolly stage warn r b g s sub ln dot sheet it fig ann board hud`. That is why the P2 warning callout is `.call.alerta`, not `.call.warn`.

## 5. Content decisions

- **No citing unofficial material.** Summaries and study guides in `fuentes/` (OPUS guide, Resumen 2025, «resumenlindo») may belong to classmates who did not give permission. Never name or cite them in the site or the READMEs; cite only the original authors and the official course material (bibliography, plate PDF, exam). All such references were removed on 2026-11-05.

- **Scope and depth** come from the course material. The Rorschach is at the LIBRE level, as the author asked.
- **Blocks added** to the request: HTP, CAT, and informe/devolución.
- **WISC-V:**
  - Labels: P1's WISC-V bands are used. A note gives the alternative labels (Muy bajo … Muy alto).
  - Conversions: the tables are labelled «ficticia, solo para mostrar el mecanismo».
  - VCs: approximate (≈), «consultar tablas B del manual».
- **Rorschach:**
  - RLC% 20–40 and A% 25–50 are taken from the explanatory text, not from the tables. A note covers this.
  - FK is used for the «monstruo visto desde abajo» in plate IV.
  - Popular responses from Beck, Piotrowski and Dana are marked ≈.
- **TAT:**
  - Spanish codes are used (VH, NM, V, N, H, M, VN, HM), with an equivalence table to the originals.
  - There is a warning about «M», which means *male* in English and *mujer* in Spanish.
  - Three labels in the course PDF were corrected.
  - Clisé perceptivo / clisé temático added (callout before the lámina 1 walkthrough, step 5, 13V example, and the «Clisé y desvíos» row in caso 4). The concept comes from the Rioplatense TAT literature (UNLP normative studies) and is marked ≈. Per-plate clisés beyond 1, 2, 5, 13V are not given.
- **Sergio's exam:**
  - The exam prints «DFH 5 → 80-110», but in the Koppitz table 80-110 corresponds to 4. A note explains this.
  - The Bender errors are not itemised in the exam, so they are given as «posibles».
- **Names:** in the Familia block example the children are Joaquín and Bruno, so they do not clash with Tomás (Caso 3) or Mateo (P1).
- **Course country:** P1 mentions Argentine norms and the WISC-IV in Argentina. That was the author's material and was left as is.

## 6. Design

- The P1 palette and type are kept: Schibsted Grotesk, Literata, Caveat and JetBrains Mono; red for developmental scores, blue for emotional indicators.
- New tokens: `--violet`, `--slate`, `--p1` (green-slate) and `--p2` (plum), each with a dark-mode variant.
- Theme is stored in `localStorage` (`hc-theme`) inside a try/catch.
- On mobile (≤ 900 px) the `.dfig` stays pinned below the topbar (56 px), and the topbar buttons show only their icons.

## 7. Verify

From `herramientas-clinicas/`:

```bash
python3 -I doc/tools/check.py                       # structure; only expected notice: '#${s.id}' (JS template)
python3 -I doc/tools/figs_preview.py [dark]         # then screenshot each out/figs_N.html:
for f in doc/tools/out/figs_*.html; do google-chrome --headless=new --disable-gpu --no-sandbox --hide-scrollbars --window-size=1360,2600 --screenshot="${f%.html}.png" "file://$PWD/$f"; done
node doc/tools/cdp.mjs "file://$PWD/index.html" doc/tools/out/d 1400 900 "p2-wisc:3800" "p2-caso5:6000"
node doc/tools/cdp.mjs "file://$PWD/index.html" doc/tools/out/m 390 844 "p2-familia:4200"
```

`cdp.mjs` reports JS errors and `scrollWidth` vs `innerWidth`; at 390 px both must be equal.

Note: `figs_preview` forces every `data-s` on but ignores `data-show`, so in the preview the per-step texts appear stacked. That is expected.
